# تطبيق نادي الحي المدرسي — الجوال

صفحة تنزيل الإصدار الكامل المخصص لأجهزة Android. التطبيق يعمل محليًا داخل الجوال، ويتضمن بيانات النادي الحالية وخصائص الأعضاء والحضور والبطاقات الرسمية والاشتراكات والتنبيهات والتقارير والاستيراد من Excel.

## التنزيل

- صفحة التنزيل: <https://yasser-dev2024.github.io/Neighborhood-Club/>
- ملف Android: `downloads/NeighborhoodClub-Mobile-v1.3.0.apk`
- الإصدار: `1.3.0+6`
- الحد الأدنى: Android 6.0
- SHA-256: `DC309E63C8C6FAE76E0915A76BF668EF604E0F79D6EAD41724B246081FBA1DD4`

## الخصوصية والأذونات

العمليات وقاعدة البيانات تعملان داخل الجهاز دون خادم. إذن المستخدم الوحيد المطلوب هو الكاميرا لقراءة QR في البطاقة الرسمية. اختيار ملفات Excel وحفظ التقارير يتمان عبر منتقي ملفات Android الآمن دون إذن وصول عام للتخزين.

فتح رسالة التجديد الجاهزة في واتساب متاح من التطبيق، بينما يتطلب إرسالها اتصال واتساب كالمعتاد.
